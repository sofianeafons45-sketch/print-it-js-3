# Print-It WebSite v.1

## GitHub Pages

Ce site est statique : il ne nécessite ni compilation ni dépendance. Les fichiers du site (`index.html`, `style.css`, `script.js` et `images/`) sont à la racine du dépôt.

Pour le publier, ouvre **Settings → Pages** dans le dépôt GitHub, choisis **Deploy from a branch**, puis sélectionne la branche **main** et le dossier **/(root)**. Enregistre : GitHub Pages publiera le site à l’adresse indiquée dans cette page.

Le carrousel de la bannière propose quatre diapositives, des flèches précédente/suivante, une navigation par points sous l’image et les touches fléchées lorsque le focus est sur ses contrôles.
